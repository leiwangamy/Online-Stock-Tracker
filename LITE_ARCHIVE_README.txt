# LeiBot LITE — online slim edition

Production site: https://stock.lwsoc.com

## What this edition is for
Online companion with:
- My Watchlist + Nasdaq-100 (full technical columns)
- Stock Tracker (charts + news)
- Sector Rotation
- Settings / Login

## What stays local (FULL only)
AI Trading, Paper Trading, AI Discovery, Market Dashboard, full Research, IBKR sync.

## Run / deploy
- Set `LEIBOT_MODE=lite` (see `docker-compose.prod.yml` / `/etc/leibot/prod.env`)
- Default without the env var is full mode in the same codebase

Related: https://github.com/leiwangamy/Online-Stock-Tracker-Full
