📖 代码说明（AI 打分 / 财报 / 新闻）
AI Score V1 = 机会分(0–100) − 风险扣分
  • 回调深度 30（离SMA越深越高，≤−30%满分）
  • 长期趋势 20（UP20 / MIXED10 / DOWN0）
  • 反弹确认 15（反弹率 + 当日方向）
  • 成交量 10（RVOL×当日方向，非越大越好）
  • 财务质量 15（🟢15 / 🟡8–12 / 🔴0–7）
  • 新闻 10（正面10 / 中性5 / 负面0）

风险扣分：严重财务 −0~15、重大负面新闻 −0~15、放量暴跌 −0~5、高波动/低流动 −0~5、临近财报 −0~15（越近扣越多）。悬停 AI 看每项拆分。绿≥70 / 黄40–69 / 红<40。

财报红旗（⚠ = 红旗，计入健康分）
  • REV 营收增长 YoY（<0 ⚠）
  • EPS 盈利增长 YoY（<0 ⚠）
  • OCF 经营现金流（负数或恶化 ⚠）
  • CUR 流动比率（<1 ⚠）
  • DEBT 负债/权益（>1.5x ⚠）
  • CASH 现金 vs 债务（现金<债务 ⚠）

显示：🟢好(0旗) / 🟡一般(1–2) / 🔴差(≥3) + 通过/已知，后面列红旗代码（如 REV− DEBT−）。悬停看每项数值。

现金流方向（同比 ↑/↓/→，仅解释不计红旗）
  • OCF 经营现金流方向
  • CAPEX 资本支出方向（↑=投资增加）
  • FCF 自由现金流方向（≈OCF−CapEx）

FCF↓ CAPEX↑ OCF↑ = 扩张投资致自由现金流下降，🟡 不一定坏； FCF↓ OCF↓ = 经营本身恶化，🔴 风险高（OCF 记红旗）； FCF↑ = 🟢 健康。CapEx 本身不算红旗。

新闻（近30天；情绪 + 正 / − 负）
  • A 财报 / 指引 ★★★★★
  • B 业务 / 产品 ★★★★
  • C 分析师 / 评级 ★★★
  • D 公司 / 管理层 ★★★★
  • E 财务 / 法律风险 ★★★★★
  • O 其他

NO NEWS = 近30天无重要新闻；NEUTRAL = 有新闻但影响中性。重大负面标红、正面标绿。悬停看标题+日期。
